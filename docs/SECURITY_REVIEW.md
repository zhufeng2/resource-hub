本轮发现的问题已修复，当前回归与所列扫描通过，可以进入服务器上的部署验证。此结论不是对生产主机、容器镜像或所有未知漏洞的认证。当前机器没有 Docker/Caddy，未实际构建镜像、装载 Caddy 配置、签发证书或验证生产网络。

## 本轮修复与优化

| 项目 | 处理 |
| --- | --- |
| 跨账号界面残留 | 浏览器会话身份改变时，同时清空旧 MCP Token 和 Cookie 界面状态；异步返回需再次匹配会话与请求版本 |
| Cookie 读取竞态 | 新请求会解除旧读取请求的过期 busy 标记，避免重叠读取后按钮一直禁用；新增浏览器回归 |
| 并发资源 | 每进程最多4个夸克子进程，每用户最多2个前台操作；归零后台最多2个任务、同用户最多1个；等候空闲资源最多5秒，返回可重试状态，不无限排队 |
| 进程边界 | 无 shell 拼接；Cookie 经 stdin 传递；子进程环境只保留必要系统变量，不继承服务器密钥；不记录 stderr 或原始错误，返回结果大小限制2 MiB |
| 写操作记录 | 抽取共享 journal 模块；创建意图与后续状态同步写入并 fsync，Linux 创建记录后同步目录；无法持久化时不提交。损坏记录停止，不能视为新操作 |
| 镜像构建范围 | 构建上下文改为仅允许 backend/web/gpt；再次排除数据库、两类密钥、Cookie 文件、任务记录、环境配置、测试和研究/浏览器资料 |
| 可重复依赖 | 新增 requirements.lock，锁定本轮实际验证的30个依赖；Docker 从锁文件安装，审计工具不进入运行依赖 |
| SQL 审查 | 两处表名来自固定集合的动态 SQL 改为固定语句；原位置没有用户输入拼接，本次改写消除扫描歧义 |

## 保持的边界

- MCP 从 Bearer Token 验证用户、有效期和精确 resource，不接受工具参数指定其他用户；任务路径按用户/绑定/请求编号隔离。重新绑定生成新命名空间。
- OAuth 使用准确回调白名单、S256 PKCE、一次性授权码、资源绑定和轮换刷新令牌；账号停用/改密码会撤销授权。
- 夸克 Cookie 使用 Fernet 加密，并在加密载荷内绑定用户和绑定 ID；不能交换两行密文后读取另一人的凭据。
- Cookie 展示仅走本人网页登录会话、同源和 CSRF 保护的 POST 接口，响应 no-store；GET 状态和 MCP 工具不返回 Cookie。按用户要求，安全页加载已保存 Cookie 并密码遮罩，切换身份或退出会清空。
- 写工具默认预览；同一操作用原 request_id 接续。已发出但结果未知的操作不盲目重提，HTTP 成功也不能代替回读核验。
- 观看进度归零要求真实指定文件夹与用户明确指令；拒绝全盘根目录，批次前检查范围，一次授权后服务器自动接续20秒预算的批次，每批最多100项、最多3项并发，每项最多上报一次后回读；后台最多运行30分钟，无进展3批暂停。服务正常退出等待当前批次释放锁；强制中断的遗留锁仍须核对。
- 文本创建仅接受非空 UTF-8 .txt/.md，最多32KiB；不覆盖同名条目，记录内容 SHA-256，不记录正文或临时上传凭据。按官网预上传、签名、单分片、完成流程上传后，从夸克下载 CDN 独立回读逐字节核验。OSS 不带账号 Cookie；仅固定的夸克自有下载 CDN 使用当前绑定 Cookie，均限制 HTTPS、公开IPv4地址、不跟随跳转。
- 上游固定夸克 API 主机，不跟随重定向；公开链接检测有域名和 HTTPS 白名单，不能由调用者指定任意内部主机。
- 文本创建请求体256 KiB（正文32KiB，留出JSON转义空间），其余请求体16 KiB；读取限时15秒；MCP 每账号每分钟120个传输请求。个人目录与分享返回只输出允许字段，签名地址和文件令牌不回传。
- 网页文本以 textContent 生成，未发现 innerHTML/eval 执行外部结果；页面有 CSP、禁止嵌入和内容类型保护，敏感 API 禁止缓存。

## 服务器上仍须完成

1. 配置真实域名、OAuth 回调、PanSou 上游地址及认证；本地预览的搜索源是占位地址，不能据此视为搜索已上线。
2. 使用生产管理员强密码，不复制本地 .cache/dev-preview 数据库或测试 Token。生产数据库和密钥不要放进代码仓库。
3. 生成并保存独立 QUARK_SECRET_KEY；若迁移已有 Cookie 数据，必须沿用对应旧密钥，否则需要重新绑定。备份数据库和两类密钥，并实测恢复流程。
4. 在服务器运行 Compose 配置检查、镜像构建、启动、健康检查及 HTTPS/OAuth/MCP 冒烟测试。详见 [部署步骤](../backend/README.md)。
5. 应用8000端口仅供可信代理和受信任内部网络访问，不直接映射公网。当前 forwarded-allow-ips=* 依赖这一网络边界；若改网络拓扑，需限定可信代理。
6. 不在代理、APM或日志中记录绑定请求体、Authorization 或 Cookie。锁文件异常时核对原任务与实际网盘结果，不能删记录或换 ID 盲试。

本服务按单机持久卷部署设计。本轮并发容量限制是每进程的；增加 worker/副本前须重新评估全局并发、SQLite与任务卷共享，不直接横向复制。
