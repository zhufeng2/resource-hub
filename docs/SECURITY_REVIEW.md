# 项目安全与清理审查

审查日期：2026-10-26。范围为仓库内网页、API、OAuth、MCP、SQLite、PanSou 适配、本地工具、安装与部署脚本。不涉及服务器 SSH、系统补丁、防火墙或线上数据操作；不代表对部署主机的安全认证。

## 已修复

| 项目 | 问题与处理 |
| --- | --- |
| 依赖 | `mcp 1.27.0` 命中安全公告，升级至兼容的 `1.30.0`。扫描返回的 7 条记录包含重复别名，对应 4 组公告；部分只影响本项目未启用的有状态会话或实验任务功能。升级后重新验证 OAuth 和 MCP。 |
| 上游地址 | 服务端及本地脚本不再默认连接项目测试站，必须显式配置实际 PanSou 地址，避免将上游凭据发往错误站点。示例改为占位域名。 |
| 响应大小 | 服务端登录、搜索和账号接口使用流式读取并限制解码后响应大小为 4 MB；本地 HTTP 工具也限制读取大小。原逻辑在完整下载之后才检查。保留不跟随重定向的限制。 |

| 记录隐私 | 定时清理同时擦除超过 24 小时的关键词及结果，保留额度和请求标识账本，不通过删除记录返还额度。清理最多延迟 5 分钟。 |
| 输入校验 | 管理员创建账号的权限字段严格要求布尔类型；搜索源地址要求字符串和 HTTPS 标准端口；链接核验统一白名单并拒绝非法端口、畸形 URL。 |
| 部署 | 应用与 Caddy 日志轮转，每容器 3 × 10 MB；镜像排除密钥、环境文件及测试资料；取消打包在线服务不使用的本地搜索脚本。 |
| 响应头 | Caddy 使用默认值补齐安全头，避免覆盖授权页的 Referrer-Policy；移除服务软件标识。应用继续提供 CSP、禁止嵌入和敏感 API 禁止缓存。 |
| 安装与缓存 | Skill 安装排除源目录中可能残留的账号配置、密钥、数据库和缓存；缓存写入失败时清理中间文件。 |

## 精简与清理

- 删除生产环境不再调用的子进程搜索适配器及其专属测试，公共异常移入 `backend/errors.py`。在线搜索继续走 `Upstream`。
- 网页与 MCP 共用链接核验规则、Bearer 解析，删除未使用导入。
- 删除旧背景、粒子、网格和深色主题的 99 处选择器或动画，以及隐藏背景 DOM；样式减少约 10.5 KB，保留浅色毛玻璃界面。
- 删除历次修复生成的 QA 截图、一次性调试脚本、npm/浏览器下载缓存、Python 字节码和临时 `node_modules`，合计约 94.2 MiB。仓库外本次及此前修复的独立截图和调试文件也已清理。
- 保留正式回归测试、第三方官方组件、账号数据与当前预览运行环境；部署记录、备份和数据库不能作为普通缓存删除。

## 部署边界与后续维护

1. 8000 端口只供受信任的反向代理网络访问，不应映射公网。现有 Uvicorn 配置信任所有代理转发头，安全性依赖该网络边界；若共享网络存在不可信容器，应配置明确的 `--forwarded-allow-ips` 地址或网段，并检查真实客户端 IP。当前未对服务器网络做验证。
2. `SOURCE_SITE_HOSTS` 由管理员配置，只允许可信的公共搜索源站点；不要填写内网、云元数据端点或不受信任的域名。
3. `update.sh` 仅更新应用容器。日志策略涉及代理容器，部署时应使用本机实际 Compose 文件组合执行完整 `up -d`，并在配置验证后重载 Caddy。此次审查没有推送或更新线上服务。
4. 清理 SQLite 内容不会保证旧页、WAL 或备份中的字节被安全覆写；备份和磁盘的访问及保留周期应由部署者管理。
5. 容器镜像和部分 Python 依赖使用版本范围，需要持续扫描；第三方夸克安装脚本下载的运行工具不在本次 Python 依赖扫描范围内。
6. `update.sh` 在存在 `compose.pansou.yaml` 时自动使用已有 PanSou 网络配置。该文件随仓库分发，独立部署者应按部署指南使用适合自己的 Compose 命令，不应假设此更新脚本适用于任意网络布局。
