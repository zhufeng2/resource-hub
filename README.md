# Resource Hub

专注夸克网盘的资源搜索与整理。网页负责搜索和账号管理，MCP 提供搜索、个人网盘查询、转存、目录整理、文本创建和观看进度归零；可选 Skill 只提供操作流程。

[在线体验](https://pan.sysscitech.com/) · [网页与账号](web/README.md) · [MCP 接入与工具](mcp/README.md) · [部署与维护](backend/README.md) · [开发指南](docs/DEVELOPMENT.md)

## 开始使用

1. 访问站点。开放注册时，点击“登录 → 注册账号”，填写用户名、邮箱、验证码和密码；未开放时由管理员创建账号。
2. 登录后搜索夸克资源，可选择公开搜索插件或频道、筛选关键词、检测链接、翻页和导出结果。不提供其他网盘类型和搜索源账号绑定。
3. 使用助手时，在“个人主页 → 安全与连接 → MCP 服务”复制地址并生成 Token，或使用客户端支持的 OAuth 连接。
4. 需要操作自己的夸克网盘时，在同页绑定自己的 Cookie。Cookie 保存在服务器，MCP 使用站点授权，不需要把 Cookie 发给助手。

普通账号默认每天 5 次公开资源搜索，额度以站点设置为准；网页与 MCP 共用额度。已有结果翻页及夸克网盘操作不产生新的公开搜索次数。结果可读取 24 小时，链接可访问不代表内容、清晰度或完整性已核验。

## 已支持的功能

| 范围 | 功能 |
| --- | --- |
| 搜索 | 仅夸克分享；插件/频道来源、关键词筛选、链接检测、分页、TXT/CSV/JSON 导出 |
| 账号 | 邮箱验证码注册与绑定、登录与修改密码、个人记录、MCP Token 管理 |
| 用户管理 | 主管理员搜索、分页、创建、编辑和删除普通账号；不展示或管理管理员账号 |
| MCP 网盘工具 | 目录与文件查询、分享目录核验、创建目录、单文件和整目录转存、改名、移动 |
| 文本与播放进度 | 创建最多 32KiB 的 UTF-8 `.txt`/`.md`；明确指定文件夹的视频进度归零，后台分批接续 |

网盘写操作默认预览；只有用户明确要求时执行。相同操作重试复用原 `request_id`，只有返回 `phase=verified` 才能按其核验范围报告完成。当前不支持删除网盘文件或任意二进制上传。

## 自行部署或安装流程说明

```bash
git clone https://github.com/zhufeng2/resource-hub.git
cd resource-hub
```

部署需要 Linux、Docker Compose、域名和可用的 PanSou 上游，按[部署指南](backend/README.md)配置。数据库和密钥由服务器运行时创建，不随 Git 推送。

已有 MCP 服务时，可以只安装流程说明：

```bash
python install.py
# 更新已安装的流程说明，先备份旧版本
python install.py --update
```

安装器默认写入 `$CODEX_HOME/skills` 或 `~/.codex/skills`，可用 `--skills-dir` 指定目录。流程说明不包含账号凭据，不安装或依赖官方夸克 Skill。
