# Resource Hub 浅色毛玻璃规范

当前以用户最新偏好为准：苹果风格的白色、简约毛玻璃，全站一套浅色外观。此前参考的 [StyleKit Glassmorphism](https://www.stylekit.top/zh/styles/glassmorphism) 中的夜景、香槟金、低于 15% 面板透明度等规则已由本次设计方向取代。

保留原始参考中的模糊、方向性高光、圆角、键盘焦点与减少动态效果支持。旧浅色/深色/系统偏好仍兼容已有配置，但不再切换外观，也不新增独立夜间模式。

## 视觉与页面映射

| 范围 | 实现 |
| --- | --- |
| 背景 | #F5F5F7 暖白底色，极淡冰蓝、灰蓝和米白径向光晕 |
| 玻璃面板 | 28% 半透明白色，顶部柔和白色高光、细灰边框、24px 圆角 |
| 深度 | 低透明度柔和阴影与顶边内高光，避免厚重黑色阴影 |
| 导航与吸顶区域 | 32% 浅色半透明背景，24px 模糊、150% 饱和度 |
| 搜索、结果与账户页 | 统一玻璃材质，内容列表内部保持平面布局 |
| 弹窗与菜单 | 32px 模糊，浅色遮罩，不叠加黑色夜景 |
| 文字 | #1D1D1F 标题，#515158 正文，#65656D 说明 |
| 主操作 | #0071E3 蓝色按钮、白色文字；高亮与焦点用 #0066CC |
| 字体 | 优先 Apple 系统字体，回退到 Segoe UI、苹方、微软雅黑 |
| 交互 | 500ms 平滑过渡、轻微上浮，移除装饰扫光 |
| 手机 | 30px 模糊、16px 输入文字、设置全屏滚动与安全区 |
| 减少动态效果 | 关闭动画、过渡与位移 |
| OAuth | 复用同一浅色主题 |

入口为 `web/static/glass.css`，在结构样式之后加载。主要 token 集中在文件开头。`startup.js` 在首屏统一设置浅色主题，已有深色偏好不会导致深色闪烁。

## 验证范围

本地模拟上游与临时账号验证，不消耗真实搜索额度。检查桌面 1440px 和 320/390/768px 宽度下的登录、设置保存、焦点返回、搜索、分页、刷新恢复、个人主页、账户弹窗、OAuth、横向溢出与减少动态效果。

玻璃质感加强：背景保留低对比度蓝/米色光晕，移除大幅弧形光带；面板保留柔和内反光，移除额外描边及导航白色分隔线。清理标题末尾点号、按钮文字中的装饰箭头、菜单尖括号和多余省略号。

对齐规范：页面滚动条槽双侧对称预留，首页说明文字使用自动水平外边距；登录介绍、空状态与弹窗标题居中，表单标签和结果正文保持左对齐。搜索框左右内边距一致。
