# 网页与账号使用

[项目首页](../README.md) · [MCP 接入与工具](../mcp/README.md) · [部署与维护](../backend/README.md)

打开[在线站点](https://pan.sysscitech.com/)或自己的部署地址。网页、MCP 和个人记录使用同一个 Resource Hub 账号。

## 注册、登录与邮箱

站点配置邮件服务且开放注册后，登录窗口会显示“注册账号”。填写用户名、密码、邮箱及收到的 6 位验证码，注册成功后登录。用户名为 3–64 位字母、数字、下划线、点或短横线，首位不能是点或短横线；密码为 12–256 个字符，管理用途名称保留。

邮箱验证通过后才创建账号，同一邮箱只能绑定一个账号。验证码 10 分钟有效，最多尝试 5 次，获取新验证码受发送频率限制。QQ、163、Gmail、Outlook 和企业邮箱等均可用于注册；发件邮箱服务商不限制收件邮箱服务商。未收到时检查垃圾邮件，稍后重试或联系管理员。

未开放注册时，请联系管理员创建账号。已有账号在“个人主页 → 安全与连接 → 绑定邮箱”补绑邮箱，验证成功后显示已验证；目前不提供网页换绑邮箱和自助找回密码。

登录仍填写用户名和密码。忘记密码时联系管理员重置，不要在聊天里发送密码、验证码、Cookie 或 Token。

## 搜索与设置

输入作品名或关键词，按 Enter 或点击“搜索”。搜索固定为夸克网盘，不显示网盘类型选项，也不提供搜索源账号登录或绑定。

| 设置 | 用途 |
| --- | --- |
| 搜索来源 | 全部来源、公开插件或频道 |
| 包含 / 排除关键词 | 筛选标题与来源，多个词用空格分隔 |
| 包含条件 | 包含任一词或全部词 |
| 排序与每页结果 | 默认或最新发布；每页 10、20、50 条 |
| 自动检测 / 隐藏失效 | 检测当前页链接，可隐藏已确认失效的结果 |
| 更多选项 | 指定插件和频道，以及配置导入、导出 |

可选来源由上游提供。更改后点击“保存并返回”；恢复默认和导入配置也要保存才生效。旧配置中的其他网盘类型会被忽略，搜索仍固定为夸克。

点击结果卡片打开分享。提取码、来源和日期按返回信息显示；“有效”仅表示链接检测通过，不能证明文件内容或全系列完整。

## 结果、记录与额度

- 默认普通账号每天 5 次公开资源搜索，管理员可调整；按搜索开始时的北京时间日期计次，零点重置。
- 成功搜索计 1 次，零结果也计次；失败不扣次数。“刷新”会创建新搜索，翻页、排序、恢复已有结果不产生新次数。
- 搜索最多保存前 200 条结果，24 小时内可重新读取。结果 URL 只能由原账号打开，分享 URL 不会授予他人读取权限。
- 导出当前筛选结果支持 TXT、CSV 和 JSON。
- 个人主页的搜索记录标题可打开结果；垃圾桶直接删除同一关键词的记录与结果，清空全部记录需确认。删除不返还已用次数，网页和 MCP 都不能再读取已删除结果。

额度、剩余次数与下次重置时间在右上角“账户信息”中查看。管理员不受每日额度限制，仍受服务限流约束。

## 安全与连接

进入“个人主页 → 安全与连接”，按同一页面完成账号和网盘连接管理。

| 分区 | 操作 |
| --- | --- |
| 修改密码 | 输入当前密码和两次新密码；成功后需重新登录，已有授权失效 |
| 绑定邮箱 | 已有账号发送验证码并验证绑定；新注册账号直接显示已验证邮箱 |
| MCP 服务 | 复制 HTTP 地址，生成、显示、复制、重新生成或撤销自己的 Token |
| 夸克网盘 | 填写一整行 Cookie 后保存，默认圆点遮罩，可显示、复制或解绑 |

MCP Token 默认自签发起有效 7 天，重新生成立即使旧 Token 失效，客户端要同步更新。连接步骤、OAuth 和所有工具说明集中在 [MCP 指南](../mcp/README.md)。

夸克 Cookie 仅在本人页面通过受保护接口提交和读取，服务端加密保存。未绑定时显示输入提示，绑定后显示遮罩；验证失败保留原绑定。更新绑定会生成新绑定标识，旧操作不会自动带入新绑定。解绑、删号不会撤销已提交给夸克的任务。

网盘的转存、改名、移动、文本创建和观看进度归零通过 MCP 执行，具体核验范围和续查规则见 [MCP 写操作](../mcp/README.md#写操作与结果核验)。

## 主管理员管理普通用户

只有名为 `admin` 且有管理员权限的账号显示“用户管理”。列表只显示普通成员，不显示或管理任何管理员账号；管理员权限由服务器维护。

- 按用户名或邮箱搜索，支持每页 20、50、100 个账号及前后翻页。
- 创建普通成员，设置每日额度；编辑时可修改密码、额度和启用状态。
- 编辑和垃圾桶图标在同一行居中排列。点击垃圾桶后，输入目标账号名确认删除。
- 删除会清理账号、网页会话、OAuth 与 MCP Token、加密 Cookie 绑定、偏好及搜索记录；账号编号不复用。已提交的网盘操作不能借此撤销。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 没有注册入口 | 站点关闭了注册，或邮件服务尚未配置；联系管理员 |
| 收不到验证码 | 检查邮箱拼写、垃圾邮件和发送间隔；管理员检查 SMTP |
| 请求失效 | 刷新站点、重新登录；维护者检查外部域名与 `PUBLIC_BASE_URL` |
| 没有搜索结果 | 尝试正式名称和别名，减少包含/排除条件，调整公开来源 |
| 登录过期、Token 失效 | 重新登录，按需重新生成 Token 或重新授权 OAuth |
| 页面或图标仍是旧版 | 强制刷新，必要时关闭站点标签页后重新打开 |
| 页面无样式 | 通过站点访问；直接打开 `web/static/index.html` 无法提供 API 和资源路由 |
