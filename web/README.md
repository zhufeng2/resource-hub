# 网页使用指南

直接使用 [Resource Hub 测试网站](https://pan.sysscitech.com/)，或访问管理员提供的站点地址。账号由站点管理员创建，目前没有自助注册和密码找回入口。

[返回项目首页](../README.md) · [MCP 接入](../gpt/README.md) · [自行部署](../backend/README.md)

## 登录与搜索

1. 输入电影、书籍、课程等资源名称，点击“搜索”或按 Enter。
2. 未登录时，按提示填写账号和密码。
3. 搜索结果在同一页面显示。点击卡片可打开分享，提取码会在结果中显示。
4. 需要调整关键词时直接修改搜索框，再次搜索。

默认搜索夸克资源，可在搜索设置中选择其他类型。搜索由外部来源返回，关键词越明确，越容易筛选出需要的内容。

## 搜索设置

点击搜索框下方的“搜索设置”。桌面端使用弹窗，手机端使用独立全屏面板。修改后点击“保存并返回”。

| 设置 | 用途 |
| --- | --- |
| 网盘类型 | 选择需要搜索的类型；不选择时搜索全部类型 |
| 搜索来源 | 全部来源、搜索插件或频道 |
| 包含 / 排除关键词 | 过滤标题与来源；多个词用空格分隔 |
| 包含条件 | 匹配任意一个词，或同时匹配全部词 |
| 排序与每页结果 | 默认排序或最新发布；每页 10、20 或 50 条 |
| 自动检测与隐藏失效链接 | 检测本页分享，按设置隐藏已确认失效的链接 |
| 更多来源与展示选项 | 指定插件、频道，以及导入 / 导出配置 |

可用插件和频道取决于站点的上游配置。恢复默认后仍需保存。导入配置会先载入设置，保存后生效。

## 结果与搜索记录

- “刷新”会重新搜索，成功后使用一次额度。
- 翻页、排序、读取已有搜索结果不使用新的搜索次数。
- “导出”可下载当前筛选结果，支持 TXT、CSV 和 JSON。
- URL 会保存搜索词和结果记录标识；同一账号可通过刷新或浏览器前进、后退恢复有效记录。
- 在“个人主页 → 搜索记录”中，可删除单条记录或清空全部记录。点击记录标题打开结果，点击垃圾桶图标直接删除单条记录；清空全部记录前会提示确认。同一关键词的重复记录会一并删除，首页最近搜索也会同步更新。
- 删除会擦除对应关键词和已保存结果，删除后无法恢复，旧结果链接和 MCP 也无法继续读取；已用搜索次数不会返还。
- 最近 24 小时内的结果可从“个人主页 → 搜索记录”重新打开。结果属于各自账号，转发结果 URL 不会赋予他人读取权限。

链接检测仅确认分享可访问情况，不证明文件画质、字幕、内容完整性或可播放性。检测不确定与确认失效是不同状态。

## 账户与个人主页

点击右上角头像打开菜单：

- **账户信息**：查看账户状态、今日已用、剩余次数和重置时间。管理员显示不限额度。
- **个人主页**：查看记录、管理搜索源账号、修改密码、查看 MCP 服务地址和管理当前账号的 Token。
- **退出登录**：结束当前网页会话。

“搜索源账号”用于连接某些来源所需的账号，支持范围以上游启用的插件为准。它与网页登录账号、夸克网盘账号分别管理。

“安全与连接 → MCP 服务”提供 Streamable HTTP 地址与当前用户的 Token，可用于支持自定义 Authorization 请求头的 MCP 客户端。Token 默认有效期 7 天，生成后可登录随时显示、隐藏或复制；搜索记录与额度归属当前账号。重新生成会立即使旧 Token 失效；单独撤销 Token 保留 OAuth。旧版仅保存哈希的 Token 需要重新生成一次才可查看。

新密码至少 12 个字符，修改后需要重新登录。没有原密码或无法登录时，联系站点管理员重置。

## 额度

普通账号默认每天 5 次，管理员可调整。每天北京时间零点重置。成功搜索计 1 次，包括零结果；失败不扣次数。网页与 MCP 共用额度，本地 Skill 的计次以所连接的搜索服务为准。

## 常见问题

**页面没有样式，像普通 HTML？**

请使用网站地址访问。不能通过 `file://` 直接打开 `web/static/index.html`；样式、脚本和 API 都需要项目服务。开发者请参阅[本地启动](../docs/DEVELOPMENT.md)。

**没有结果？**

检查网盘类型、包含 / 排除词和来源限制，尝试作品全名或别名。没有结果不一定表示所有来源都没有该资源。

**登录过期或额度不足？**

重新登录，或在账户信息中查看额度及重置时间。需要增加额度时联系管理员。

**搜索源账号连接失败？**

上游必须提供该来源的绑定接口。普通搜索可用，不代表所有绑定功能都可用；可向管理员提供报错信息。

**更新后界面或标签页图标没有变化？**

先强制刷新页面；浏览器仍保留旧图标时，可关闭站点标签页后重新打开。

## 其他入口

网页提供搜索和结果管理。需要在助手里搜索，请阅读 [MCP 接入指南](../gpt/README.md)；需要夸克转存，可通过 MCP 直接操作，或使用[本地 Skill](../skills/resource-hub/SKILL.md)编排流程。

## 绑定自己的夸克网盘

进入“个人主页 → 安全与连接 → 夸克网盘”，填写一整行 Cookie 并验证保存。凭据只在此页面提交，服务器加密保存，默认隐藏，显示和复制仅在本人主动点击时读取；不要发送到聊天。绑定后当前用户已授权的 MCP 客户端可读取网盘、转存和创建目录。

更新绑定会隔离旧任务，因此有未完成操作时先查询原结果。解除绑定后不能再发起新操作，但已提交的任务可能继续。凭据校验失败保留原绑定。这里的绑定与“搜索源账号”相互独立。
