# 网页

`app.py` 提供网页接口，`static/` 包含页面、样式及交互；共用服务入口为 `backend.app:create_app`。部署方式见 [部署说明](../backend/README.md)。

- `/`：居中搜索主页，搜索后在原页面展示结果。
- `/profile`：搜索记录、搜索源账号、安全设置和用户管理。
- 搜索框下方的齿轮打开独立设置面板：手机为全屏子面板，桌面为弹窗；返回时保留搜索页面位置，保存成功后返回搜索。账号额度位于头像菜单的“账户信息”。
- URL 保存关键词、筛选条件和结果记录；恢复已有结果不重新消耗搜索次数。
- 首屏在样式加载前读取本机外观偏好，减少刷新时亮暗切换；手机背景使用稳定的静态渐变，输入框聚焦、失焦不再重新播放入场动画。桌面保留轻量背景动画。

## 手动验收

1. 打开根路径，输入关键词，检查 Enter、清除与搜索。
2. 搜索后修改关键词，再刷新、前进和后退，检查查询及结果恢复。
3. 点击齿轮打开搜索设置，检查修改、保存并返回、恢复默认、返回搜索及配置导入导出。检查返回后原页面的滚动位置，桌面检查 Escape 关闭与焦点返回。
4. 点击头像，查看账户信息；进入个人主页检查历史、搜索源及账号管理。
5. 检查无结果、请求失败重试、登录过期和额度不足提示。
6. 在手机与桌面检查布局、键盘焦点及“减少动态效果”模式。
7. 手机切换深色后刷新，反复弹出和收起键盘；确认首屏主题稳定，搜索框不重播入场动画，设置面板的输入项和保存按钮可访问。
